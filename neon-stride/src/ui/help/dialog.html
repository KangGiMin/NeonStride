도시를 달리는 방법

자동으로 달리는 러너를 조작해 장애물과 낭떠러지를 피하세요. 난이도는 시작 전이나 게임 오버 후 선택할 수 있습니다.

  • SPACE / ↑ / W — 점프. 공중에서 다시 누르면 2단 점프!
  • ↓ / S — 슬라이딩. 누르고 있는 동안 낮게 숙입니다.
  • P / ESC — 일시 정지 및 계속 달리기
  • ← / → — 누르는 동안 도로 안에서 좌우 이동
  • SHIFT + ← / → — 노란 코너 표식 구간에서 안내 방향으로 90° 회전
  • 모바일 — 화면의 점프·슬라이드 버튼 사용. 화면을 위로 스와이프하거나 탭하면 점프, 아래로 스와이프하면 슬라이딩. 좌우 버튼을 누르거나 옆으로 스와이프하면 이동합니다. 코너 입력 구간에서는 좌우 버튼·스와이프가 회전으로 바뀝니다.

슬라이딩: 얼굴을 노리는 괴물의 방망이, 가로 불기둥, 보라색 게이트.
점프: 청록색 방벽, 쓰러진 나무 한 그루.
2단 점프: 괴물의 방망이, 주황색 높은 방벽, 겹쳐 쓰러진 나무 두 그루, 낭떠러지, 철골 낙하로 붕괴한 도로. 에너지 파괴광선도 2단 점프로 넘으세요.

새 보안 장치: EMP 구역은 화면에 약한 노이즈만 주며 충돌하지 않습니다. 순찰 드론·호버 봇은 좌우로 왕복하므로 빈 공간으로 이동하세요. 셔터는 닫히는 중이면 슬라이드, 열리는 중이면 점프로 통과합니다. 공중 드론 3대는 바닥에 위치를 고정해 조준한 뒤 순서대로 발사합니다. 붉은 표식 밖으로 좌우 이동하세요.
