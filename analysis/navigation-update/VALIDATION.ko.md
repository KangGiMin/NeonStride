# 좌우 이동·90° 코너·보안 장애물 확장 검증

작업일: 2026-11-19 (한국 시간).

## 반영 내용

- 방향키를 누르는 동안 도로 폭 안에서 좌우 이동하며 키를 놓으면 멈춥니다.
- 코너의 위치와 방향은 무작위입니다. 3초 전 안내, 도착 0.6초 전부터 0.16초 후까지 `Shift + ←/→` 입력, 교차로에서 90° 회전과 카메라 전환을 구현했습니다.
- 코너를 놓치거나 입력 방향이 틀리면 종료됩니다. 다른 장애물은 코너 예약 구간 밖에서 생성됩니다. 앞쪽 코너를 충분히 미리 생성하고 예상 속도를 사용해 가속 후에도 회전 구간을 확보합니다.
- 에너지 파괴광선은 2단 점프로 넘습니다.
- EMP는 비충돌 구역이며 약한 노이즈·화면 간섭을 적용합니다. 모션 감소 설정에서는 화면 복사를 생략하고 효과를 줄입니다.
- 순찰 드론·호버 봇은 도로 좌우를 일정 속도로 왕복하며 좌우 이동으로 회피합니다.
- 셔터는 열림·닫힘 두 변형입니다. 닫히는 문은 슬라이드, 열리는 문은 점프로 통과합니다.
- 공중 드론 3대는 각각 바닥의 위치를 고정 조준한 다음 순차 발사합니다. 조준점은 고정된 뒤 플레이어를 따라가지 않으며 점프 대신 옆으로 피해야 합니다.
- 난이도 버튼은 초록·노랑·빨강·보라로 구분합니다.
- 터치 환경에서는 좌우 버튼·스와이프를 지원하고, 코너 입력 구간에는 회전으로 전환합니다. 작은 세로·가로 화면의 배치도 보완했습니다.
- README, 조작 안내, 검색 설명과 단일 HTML 배포판을 갱신했습니다. 기능별 테스트로 이전된 레거시 중복 테스트 3개 파일을 정리했습니다.
